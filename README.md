# Candy Match Three

A fun and engaging match-three puzzle game inspired by Candy Crush Saga! 🍬

## About

This project is a match-three style puzzle game where players swap adjacent tiles to create matches of three or more identical candies. With colorful graphics, satisfying animations, and progressively challenging levels, it provides an entertaining gaming experience.

## Features

- 🎮 Classic match-three gameplay mechanics
- 🎨 Colorful candy graphics and smooth animations
- 📊 Score tracking and level progression
- ✨ Special tile combinations and power-ups
- 🏆 Engaging puzzle challenges

## Getting Started

### Prerequisites

- Node.js (v14 or higher)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/emmymocular-afk/candy-match-three.git
   cd candy-match-three
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure your environment (if needed):
   - Copy `.env.local` and add any required API keys

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to the local development URL
